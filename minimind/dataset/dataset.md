# MiniMind Datasets

Please download the following dataset files from the link below and place them in the **current working directory**:

🔗 **Dataset Source:**  
https://www.modelscope.cn/datasets/gongjy/minimind_dataset/files

📄 **Files to Download:**
- `pretrain_t2t_mini.jsonl`
- `sft_t2t.jsonl`
- `agent_rl.jsonl`

After downloading, make sure all three files are located in the same folder where you will run your training or inference scripts.
